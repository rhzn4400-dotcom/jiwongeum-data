# jiwongeum-data

「지원금받기」 앱이 내려받는 공공서비스(혜택) 데이터 파일을 배포하는 저장소입니다.

- **파일**: [Releases](../../releases) 에 매일 올라갑니다. 앱은 항상 최신 릴리스(`releases/latest/download/manifest.json`)를 받습니다.
  - `manifest.json` — 데이터 버전 · 받은 시각 · 건수 · 파일 SHA-256
  - `services.json.gz` — 공공서비스 목록 · 지원조건 · 상세 (신청기한을 날짜로, 소관기관명을 지역으로 가공)
- **출처**: 행정안전부 「대한민국 공공서비스 정보」 (공공데이터포털, 이용허락범위 제한 없음)를 가공한 데이터입니다.
- **개인정보처리방침**: https://rhzn4400-dotcom.github.io/jiwongeum-data/

이 저장소에는 이용자 정보가 올라오지 않습니다. 앱은 이 파일들을 내려받기만 하고, 조건 맞춤은 모두 기기 안에서 합니다.
이 앱과 저장소는 정부·공공기관과 관계가 없습니다.
